# 現代文単語

スマホで使う現代文単語の学習アプリ（Liquid Glass UI）。ビルド不要の静的サイトです。

## 機能

- **単語カード** — タップでめくり、「覚えた / まだ」で仕分け。表に出す面を「語 → 意味」「意味 → 語」で切り替え可能。カテゴリと学習状況（すべて／未学習／ミスした／未習得／覚えた／★）で絞り込み、シャッフル。終わったら「まだ」にした分だけもう一度
- **4択クイズ** — 語→意味／意味→語／ミックス。5〜30問。間違えた問題だけ解き直し
- **単語一覧** — 語・読み・意味・整理番号で検索、カテゴリ・習得状況・★で絞り込み、詳細シートで状態を変更
- **苦手な単語** — 間違えた語と★をつけた語を自動で集めて復習
- 学習記録は端末の `localStorage` に保存
- **左→右スワイプでサイドバー**（画面のどこからでも）。右→左で閉じる
- **スワイプで「戻る」が起きない**：画面端のタッチでブラウザの戻る操作を止め、それでも戻る操作が来たときはページを離れずにサイドバーを開く
- ホーム画面に追加すると全画面アプリ（PWA）として動作
- ライト / ダークモード対応

## 単語の追加

`data/words.js` の `window.WORDS` 配列にオブジェクトを足すだけです。

```js
{
  no: 1,                        // 整理番号（任意・重複不可）。一覧やカードはこの順に並び、番号で検索もできる
  word: "恣意",                 // 見出し語（必須・重複不可）
  reading: "しい",              // 読み（任意・入れるのがおすすめ）
  meaning: "自分勝手な考え。…",  // 意味（必須）
  example: "言葉と意味の…",      // 例文（任意）
  category: "評論の基本語",       // カテゴリ（任意。新しい名前で自動的にカテゴリが増える）
  synonyms: ["任意"],           // 類義語（任意）
  antonyms: ["特殊"],           // 対義語（任意）
},
```

`no` は数値でも `"A-12"` のような文字列でもOK（数字部分は自然な順で並びます）。番号のない語は末尾に並びます。

詳細シート（下から出るポップアップ）は、上の掴み部分を下に引っ張ると閉じます。

学習記録は `word` をキーに保存されるため、見出し語を書き換えるとその語の記録はリセットされます。

## ローカルで確認

```sh
npx http-server -p 8080 .
```

## 構成

```
index.html            画面の骨組み
css/style.css         Liquid Glass のスタイル
js/app.js             画面・学習ロジック・スワイプ処理
data/words.js         単語データ
manifest.webmanifest  PWA 設定
sw.js                 オフライン用（ネットワーク優先）
icons/                アイコン
```
